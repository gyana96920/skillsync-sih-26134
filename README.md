# SkillSync — SIH PS 26134

Interactive prototype for labour-market intelligence and curriculum alignment.

## Scope
- Labour-market demand signals
- Skill demand and skill-gap analysis
- Curriculum alignment and recommendations
- Employer requirement validation
- District-level training planning
